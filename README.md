# Projetideias — site da agência

Site institucional da **Projetideias**, agência de marketing digital: tráfego pago, conteúdo, branding e criação de sites.

🔗 **Domínio:** https://projetideias.com

## Destaques
- Página única com secções de serviços, portfólio, processo, FAQ e contacto
- Tipografia própria alojada localmente (DM Sans, DM Mono, Playfair Display, Outfit), sem dependência de serviços externos
- Imagens otimizadas em WebP, favicons e imagem Open Graph para partilhas
- Animações em JavaScript puro, responsivo e sem frameworks

## Tecnologias
HTML5 · CSS3 · JavaScript

## Como abrir
Abra `index.html` no navegador, ou publique a pasta em qualquer alojamento estático (Netlify, Vercel, GitHub Pages).
